# 🚀 Quick Setup for Friends

## What You Need:
- Node.js installed (https://nodejs.org/)
- A phone with Expo Go app

## Setup (3 Commands):

```bash
# 1. Go to project folder
cd MedicineTracker-Mobile

# 2. Install everything
npm install

# 3. Start the app
npm start
```

## Open on Phone:
1. Install "Expo Go" from Play Store/App Store
2. Scan the QR code that appears
3. App opens! 🎉
